# 🚀 盘古AI内容引擎 — Pangu AI Content Engine

> 面向中小微企业的一站式AI内容工厂：文案+图片+视频脚本+直播话术+数据闭环

---

## 和小鱼AI的本质区别

| 维度 | 小鱼AI | 盘古 |
|------|--------|------|
| 能力 | 单次文字生成 | 文字+图片+视频脚本+直播话术 全模态 |
| 深度 | 通用模板 | 6大行业深度定制，懂行话/痛点 |
| 智能 | 被动生成 | 主动竞品分析+策略建议 |
| 输出 | 一段文案 | 完整内容日历，多平台一键适配 |
| 学习 | 无 | 学习老板风格，越用越像本人 |
| 闭环 | 写完即止 | 发布→数据回传→优化迭代 |

## 功能全景

```
📊 策略层：竞品爆款分析 | 内容日历生成 | 账号诊断
✍️ 创作层：一键多平台改写 | 爆款标题工厂 | 长文写作 | 行业场景库 | 洗稿重写
🎨 视觉层：AI配图生成 | 海报文案+设计描述 | 封面图生成
📹 视频层：口播脚本 | 带货脚本 | Vlog分镜 | 直播话术
📈 运营层：数据看板 | AI回复评论 | 周报自动生成
```

## 技术栈

- **AI引擎**：DeepSeek v4-pro（文案）+ ComfyUI SD1.5（配图）+ Edge TTS（配音）
- **后端**：Node.js + Express + OpenClaw Gateway
- **前端**：React 18 + Vite + Tailwind CSS
- **数据**：SQLite（本地）+ 飞书多维表格（云端看板）
- **入口**：Web App + 飞书群机器人 + 微信

## 快速启动

```bash
cd E:\盘古AI内容引擎
npm install
npm run dev
```
