## 📌 产品能力

### Q1：盘古能做什么？
盘古是一站式AI内容工厂，覆盖**文案写作、图片生成、视频脚本、直播话术、内容日历**全场景。你选行业、选平台、说需求，盘古帮你出内容——从一条朋友圈到一整月的内容日历，全搞定。

### Q2：盘古和ChatGPT、文心一言这些通用AI有什么区别？
ChatGPT是通才，盘古是**垂直行业的内容专家**。盘古内置6大行业（美业/餐饮/零售/教育/健身/家装）深度模板，懂行话、懂痛点、懂平台规则。你不用写长篇Prompt，选行业点两下就出活。

### Q3：盘古支持哪些平台？
抖音、小红书、微信朋友圈、知乎、公众号——5个主流平台全覆盖，且**每个平台自动调整风格**：抖音带话题标签+快节奏，小红书精致种草风，朋友圈亲切自然，知乎深度专业，公众号结构化排版。

### Q4：盘古支持哪些行业？
6大行业深度覆盖：**美业**（美容/美发/美甲）、**餐饮**、**零售**、**教育**、**健身**（健身房/瑜伽/普拉提/私教）、**家装**。每个行业都有专属Prompt模板，懂行业术语和痛点。不在这些行业也能用通用模式生成。

### Q5：能生成图片吗？
Pro版及以上支持。盘古生成的是**AI配图Prompt**（中文+英文双语，包含构图、光线、色调、风格描述），你复制Prompt到ComfyUI或Stable Diffusion就能出图。当前版本是两步走，后续会实现全自动直连出图。

### Q6：视频能直接生成成品视频吗？
目前盘古生成的是**视频分镜脚本**（口播/带货/Vlog三种类型），不是成品视频。脚本包含每段台词、镜头描述、时长分配、配乐建议，直接拿去拍就行。

### Q7：直播话术能覆盖哪些环节？
全套直播间话术：①开场暖场→②产品讲解→③答疑逼单→④收尾预告，从欢迎词到下播全链路覆盖。你填入产品、价格、时长，盘古给你主播稿。

## 💰 定价与套餐

### Q8：免费版有什么？够用吗？
免费版永久免费，**每天5次生成**，包含：基础内容生成、标题工厂、内容日历、视频脚本。对于每天发1-2条朋友圈/帖子的小个体户，完全够用。

### Q9：Pro版和免费版的核心区别？
Pro版（¥299/月）**每天100次**，且解锁三大高阶能力：①多平台一键改写（输入一次同时出5个平台版本）②竞品分析+策略建议③AI配图+直播话术。适合需要稳定高频产出的个人创业者和门店老板。

### Q10：Pro版和企业版的核心区别？
- **Pro版（¥299/月）**：100次/天，单账号，全功能，适合个人
- **企业版（¥999/月）**：无限生成，多账号（最多10个），数据看板+运营分析+AI自动回复评论，适合有内容团队的商家

### Q11：白标版是什么？
白标版（¥3999/月）是**代理商模式**。你用自己的品牌名（Logo、域名、UI全换）对外销售，底层引擎用盘古。独立数据库，无限子账号，定价权归你，利润全归你。适合AI内容代运营团队或想贴牌卖AI工具的SaaS创业者。

### Q12：能按月付吗？有年付优惠吗？
默认月付，随时可升级/降级。年付优惠请联系客服咨询。

### Q13：不满意能退款吗？
Pro版和企业版支持7天无理由退款。白标版涉及品牌定制，需签约前充分沟通。

## 🔧 使用方式

### Q14：怎么开始用？
三步上手：①打开 http://localhost:18790 注册（手机号+密码，30秒）②选行业→选平台→选场景→填业务信息 ③点生成，几秒钟出结果。全程不用学，不需要会写Prompt。

### Q15：支持手机吗？
支持。Web App是响应式设计，手机浏览器打开就能用，体验跟App一样。

### Q16：能在飞书群里用吗？
能。在飞书群里 @盘古，直接发指令就能生成内容，适合团队协作场景。

### Q17："一键多平台改写"具体怎么用？
输入一次核心信息（行业+场景+产品卖点），勾选目标平台，盘古同时生成各平台适配版本。比如：同一款新品，小红书出精致种草文，抖音出带话题的短视频文案，朋友圈出亲切推荐，知乎出专业分析，公众号出结构化长文。用量按平台数计算（生成5个平台消耗5次）。

## 📊 内容质量

### Q18：AI写的内容质量怎么样？会不会很"AI味"？
盘古的行业Prompt模板经过深度调优——美业模板懂"水光针"和"光子嫩肤"的区别，餐饮模板知道"翻台率"和"客单价"怎么写进文案。配合6行业×5平台×6工具=720+Prompt组合，输出比通用AI自然得多。

### Q19：生成的内容能直接用吗？
标题、朋友圈文案、口播脚本这类短内容大部分可以直接用。长文章和公众号内容建议花几分钟微调，加入你自己的案例和经验，效果更好。盘古提供的是高质量初稿，不是你直接Ctrl+C/V就完事的东西。

### Q20：会和其他用户生成重复内容吗？
不会。每次生成都是实时调用DeepSeek，内容不缓存、不重复。行业模板是框架，但具体输出根据你的需求实时生成。

### Q21：历史记录保存多久？
永久保存，无自动清理。你可以翻页浏览、搜索关键词查找以前的内容，也可以复制复用。

## 🔒 数据安全

### Q22：我输入的内容会不会被拿去训练AI？
不会。你的输入数据和生成内容都属于你。盘古不做用户数据训练。

### Q23：白标版的数据隔离吗？
完全隔离。白标版独立数据库、独立用户体系，你的客户数据和盘古主产品互不相通。

## 🔧 部署与技术

### Q24：盘古怎么部署？
5分钟部署：安装Node.js 18+ → git clone → npm install → 配置DeepSeek API Key → npm run dev。详见《部署文档》。支持Windows/macOS/Linux。

### Q25：需要什么技术条件？
- 必需：Node.js 18+，DeepSeek API Key
- 可选：ComfyUI（AI配图）、Edge TTS（配音）
- 磁盘空间：≥500MB

### Q26：密码忘了怎么办？
当前版本联系管理员重置，后续版本会增加自助找回密码功能。

### Q27：有管理后台吗？
有。管理员在 http://localhost:18791 登录后可以：查看仪表盘（用户数/内容量/日活/收入预估）、管理用户（搜索/套餐调整/删除）、管理内容、切换AI模型。
