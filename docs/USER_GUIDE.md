## 快速开始（5分钟）

### 第1步：打开盘古

浏览器访问 **http://localhost:18790**。

> 推荐使用 Chrome 或 Edge 浏览器，手机端同样适配。

### 第2步：注册账号

点击右上角「登录/注册」→ 输入手机号和密码 → 点「注册」。

> 新用户自动获得**免费版**套餐，每天可生成 5 次。

### 第3步：开始生成

在左侧菜单点击「✍️ 智能生成」，然后：

1. **选行业**：下拉选择你的行业（美业/餐饮/零售/教育/健身/家装）
2. **选平台**：选择要发布的平台（抖音/小红书/朋友圈/知乎/公众号）
3. **选场景**：促销活动、新品上市、日常分享或节日营销
4. **填信息**：输入你的业务信息（产品名、价格、卖点等）
5. **点生成**：等待几秒，AI 为你生成专业文案

### 第4步：复制使用

生成结果展示在页面上，点击「复制」按钮即可粘贴到任意平台发布。

**🎉 恭喜！你已经会用盘古了。**

## 注册与登录

### 注册

1. 打开 http://localhost:18790
2. 点击右上角「登录/注册」按钮
3. 输入**手机号**和**密码**
4. 可选填昵称（方便团队识别）
5. 点击「注册」

![注册页面截图](screenshots/register.png)

> ⚠️ 手机号是唯一标识，不能重复注册。如果提示"该手机号已注册"，请直接登录。

### 登录

1. 切换到「登录」标签
2. 输入已注册的手机号和密码
3. 点击「登录」

登录成功后，系统记住你的身份（关闭浏览器后需重新登录）。

### 退出

点击右上角用户名 → 退出登录。退出后清除本地 Token。

## 功能详解

### 首页 🏠

登录后默认进入首页。这里展示：

- **功能导航卡片**：快速跳转到各功能模块
- **今日用量**：今日已生成次数 / 每日上限
- **套餐信息**：当前套餐和升级入口

### 智能生成 ✍️

> 核心功能：一个行业 + 一个平台 + 一个场景 = 一篇专业文案

**操作步骤：**

1. 从左侧菜单进入「智能生成」
2. **选择行业**（下拉框）— 盘古内置6大行业深度模板，选择最接近你的行业
3. **选择平台**（下拉框）— 不同平台风格不同：
   - 抖音：强视觉、快节奏、话题标签
   - 小红书：种草风、emoji、个人体验
   - 微信朋友圈：亲切、生活化
   - 知乎：深度、理性、专业知识
   - 公众号：正式、结构化、排版优化
4. **选择场景**（下拉框）— 促销/新品/日常/节日，AI 会自动调整语气和策略
5. **填写业务信息**（文本框）— 输入你的产品名、价格、核心卖点。越具体效果越好
6. **点击「生成」按钮**

**示例：**

假设你是一家美甲店老板，要发小红书推广新款猫眼美甲：

| 字段 | 填写内容 |
|------|----------|
| 行业 | 美业 (beauty) |
| 平台 | 小红书 |
| 场景 | 新品上市 |
| 业务信息 | 产品：极光猫眼美甲，价格：198元，卖点：低调奢华、适合秋冬、显白 |

点击生成后，盘古会返回一篇符合小红书调性的种草文案。

**💡 技巧：** 业务信息写得越详细，生成效果越好。包含产品名、价格、卖点、目标人群等关键信息。

### 一键多平台 🔄

> 杀手功能：输入一次，同时生成5个平台版本。

**使用场景：** 你有一篇核心文案（比如新品上市），需要同时发到小红书、抖音、朋友圈、知乎、公众号。传统方式要手动改写5次，盘古一键搞定。

**操作步骤：**

1. 进入「一键多平台」
2. **选行业** + **选场景** — 和智能生成一样
3. **填业务信息** — 把你的核心卖点写清楚
4. **勾选目标平台** — 默认全选，可以只选需要的平台
5. 点击「一键生成」

盘古会依次生成每个平台版本，展示在结果区。

**每个平台生成效果：**
- 小红书：精致图文风，带 emoji
- 抖音：短视频配套文案，带话题标签
- 朋友圈：亲切自然的推荐语气
- 知乎：专业深入的分析角度
- 公众号：结构化长文框架

> ⚠️ 用量说明：生成 N 个平台版本，消耗 N 次额度。

### 标题工厂 💥

> 批量生成爆款标题，告别标题困难症。

**操作步骤：**

1. 进入「标题工厂」
2. 输入**主题**（如"夏季防晒推荐"）
3. 选择**平台风格**（小红书/抖音等）
4. 设置**生成数量**（默认20条）
5. 点击生成

生成的标题包含 emoji、话题标签、疑问句、数字对比等多种爆款公式。

**💡 技巧：** 生成后挑2-3条最喜欢的，可以直接配上正文发布。

---

### 内容日历 📅

> 一个月的内容规划，AI 帮你排好。

**操作步骤：**

1. 进入「内容日历」
2. 选择**行业**
3. 选择**月份**（如 2026年8月）
4. 可选添加**关键日期**（如"8月8日店庆"、"8月15日七夕"）
5. 点击生成

盘古会输出按周排列的内容日历，包含：
- 每周主题方向
- 具体文案角度
- 发布平台建议
- 发布时间建议

---

### 视频脚本 🎬

> 短视频脚本一键生成，口播/带货/Vlog 全支持。

**操作步骤：**

1. 进入「视频脚本」
2. 选择**脚本类型**：口播 / 带货 / Vlog
3. 输入**主题**和**时长**（如"无线耳机推荐，60秒"）
4. 选择**风格**（如"科技感、年轻化"）
5. 点击生成

生成结果包含完整分镜：
- 每段台词
- 镜头语言描述
- 时长分配
- 配乐建议

### 直播话术 📡

> 直播间全套话术，从开场到逼单一步到位。

**操作步骤：**

1. 进入「直播话术」
2. 填写**行业**、**产品**、**价格**、**预计时长**
3. 点击生成

输出话术结构：
1. 🎤 开场暖场 — 欢迎话术 + 直播间互动
2. 📦 产品讲解 — 核心卖点 + 使用演示
3. ❓ 答疑逼单 — 处理犹豫 + 限时优惠
4. 👋 收尾预告 — 下播话术 + 下次预告

### 竞品分析 🔍

> 分析竞品策略，找到你的差异化优势。

**操作步骤：**

1. 进入「竞品分析」
2. **两种输入方式任选**：
   - 粘贴竞品文案内容
   - 输入竞品内容链接
3. 选择**行业**（提高分析精准度）
4. 点击「分析」

盘古会输出：
- 📊 竞品策略拆解（目标人群、内容策略、转化路径）
- 💡 你的差异化建议
- ✍️ 优化版参考文案

### AI 配图 🎨

> 生成 Stable Diffusion / ComfyUI 配图 Prompt，让你的文案图文并茂。

**操作步骤：**

1. 进入「配图生成」
2. 粘贴你的**文案内容**
3. 选择**视觉风格**（现代简约、清新自然、科技感等）
4. 点击生成

输出内容：
- **简短版 Prompt**：用于快速测试效果
- **完整版 Prompt**：中英双语，含构图/光线/色调/风格/质量词，直接用于 ComfyUI 出图

> 配图 Prompt 需要配合 ComfyUI 引擎使用，详见《部署文档》。

## 常见问题

### Q: 生成的文案能直接用吗？

**A:** 盘古生成的文案是高质量的基础版本，建议你做两件事：
1. 替换模板中的占位信息（如有）为你实际的信息
2. 加入你个人的表达风格（盘古会越用越像你的风格）

### Q: 免费额度用完了怎么办？

**A:** 第二天自动重置。如果想立即继续使用，可以升级到 Pro 版（¥299/月，每天100次）。

### Q: 支持哪些行业？

**A:** 当前支持6大行业：美业、餐饮、零售、教育、健身、家装。每个行业都有深度定制的 Prompt 模板。需要更多行业可以联系开发团队添加。

### Q: 配图功能怎么用？

**A:** 盘古生成的是图片 Prompt（提示词），你需要配合 ComfyUI 或 Stable Diffusion 使用。Prompt 直接粘贴到 ComfyUI 的正向提示词框即可出图。

### Q: 多平台改写和单次生成有什么区别？

**A:** 单次生成是选择一个平台生成一篇；多平台改写是一键生成所有选中平台的版本，效率更高。但多平台改写的用量按平台数计算（生成5个平台消耗5次）。

### Q: 历史记录保存多久？

**A:** 当前版本无自动清理，永久保存。管理员可手动清理。

### Q: 忘记密码怎么办？

**A:** 当前版本暂无自助找回密码功能。请联系管理员重置。

### Q: 手机号可以改吗？

**A:** 当前版本不支持自助修改手机号，请联系管理员。
