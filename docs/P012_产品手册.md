## 1. 产品介绍

### 盘古是什么？

盘古AI内容引擎是一个**一站式AI内容工厂**，专为中小微企业打造。它能帮你完成：

- ✍️ **写文案** — 朋友圈、小红书、公众号、抖音…一个平台一个风格
- 🎨 **出配图** — AI配图Prompt，直接用于出图
- 📹 **写脚本** — 口播、带货、Vlog分镜，拿稿就能拍
- 📡 **排话术** — 直播间全套话术，开场到逼单一步到位
- 📅 **排日历** — 一个月的发布计划，AI帮你规划好
- 🔍 **看竞品** — 分析对手策略，找到你的差异化

### 解决什么问题？

| 你的痛点 | 盘古的方案 |
|----------|-----------|
| 每天想发什么想破头 | 内容日历+标题工厂，选题不用愁 |
| 小红书/抖音/朋友圈要分别写 | 一键多平台改写，一条变五条 |
| 不懂怎么写才吸引人 | 6大行业模板，懂你行话和痛点 |
| 请不起文案/设计 | 299元/月，一条内容不到1毛钱 |
| 发了没效果不知道怎么优化 | 数据回传+竞品分析，越用越聪明 |

### 盘古 vs 通用AI

| 对比维度 | ChatGPT/文心一言 | 盘古 |
|----------|-----------------|------|
| 能力范围 | 通用对话+文字 | 文字+配图+视频脚本+直播话术全模态 |
| 行业理解 | 需自己写长Prompt | 6大行业深度模板，选行业即用 |
| 平台适配 | 自己手动改 | 一键生成5平台适配版本 |
| 内容规划 | 无 | 月度内容日历+数据回传闭环 |
| 上手难度 | 需要学Prompt技巧 | 选行业→填需求→出结果，三步搞定 |

## 2. 核心能力

### 📊 策略层

**内容日历** — 按月生成发布计划，包含每周主题、文案角度、平台+发布时间建议。支持自定义关键日期（店庆/节日/活动日）。

**竞品分析** — 粘贴竞品文案或链接，盘古拆解其策略（目标人群/内容策略/转化路径），给你差异化建议和优化版文案。

**数据看板**（企业版+）— 内容表现追踪、运营分析、周报自动生成。

### ✍️ 创作层

**智能生成** — 盘古核心：选行业+选平台+选场景+填业务信息 → 专业文案。4种场景（促销/新品/日常/节日）× 6行业 × 5平台。

**一键多平台改写** — 杀手功能。输入一次核心信息，同时出5个平台版本。一条变五条，效率翻5倍。

**爆款标题工厂** — 批量生成高点击率标题，含emoji、话题标签、多种爆款公式。支持选择平台风格。

### 🎨 视觉层

**AI配图Prompt** — 将文案转化为专业配图Prompt（中英双语）。包含构图、光线、色调、风格描述、质量词，直接用于ComfyUI/Stable Diffusion出图。

### 📹 视频与直播层

**视频脚本** — 三种类型：口播脚本、带货脚本、Vlog分镜。输出包含镜头描述+台词+时长分配+配乐建议。

**直播话术** — 全套直播间话术：开场暖场→产品讲解→答疑逼单→收尾预告。填入产品和价格，直接上播。

## 3. 行业方案

盘古为6大行业提供深度定制的Prompt模板，懂行话、懂痛点、懂转化。

### 💅 美业（美容/美发/美甲）

- **典型场景：** 项目上新 → 写小红书种草文 → 生成前后对比配图Prompt
- **懂得：** "水光针"和"光子嫩肤"的区别、季节对美甲颜色的影响、团购引流转化话术

### 🍜 餐饮

- **典型场景：** 新菜上市 → 抖音带货脚本 → 朋友圈限时活动文案
- **懂得：** "翻台率"怎么写进文案、"客单价"引导技巧、外卖vs堂食差异化表达

### 🛍️ 零售

- **典型场景：** 换季促销 → 公众号长文+小红书种草矩阵 → 直播话术
- **懂得：** 零售话术体系、比价心理学、限时紧迫感营造

### 📚 教育

- **典型场景：** 开学季 → 知乎专业长文 → 朋友圈家长见证 → 直播招生话术
- **懂得：** 家长决策心理、课程体系如何写得专业可信、"免费试听"的多种表达

### 💪 健身

- **典型场景：** 新课上线 → 小红书蜕变故事 → 抖音训练片段脚本 → 私教转化话术
- **懂得：** 马甲线/减脂/增肌的差异化文案、"21天变化"的叙事结构、私教转化技巧

### 🏠 家装

- **典型场景：** 案例展示 → 小红书前后对比 → 知乎装修避坑指南 → 朋友圈客户见证
- **懂得：** "全包vs半包"的写法、"避坑"选题体系、实景案例的叙事方式

## 4. 平台适配

盘古自动根据平台调性生成不同风格的文案，不需要你手动改。

| 平台 | 风格特点 | 盘古自动适配 |
|------|----------|-------------|
| 🎵 抖音 | 强视觉、快节奏、话题标签 | 加 #话题、口语化、短句节奏感 |
| 📕 小红书 | 种草风、emoji、个人体验 | 精致图文风格、"姐妹们"语气 |
| 💬 微信朋友圈 | 亲切生活化、朋友推荐 | 聊天语气、减弱营销感 |
| 📖 知乎 | 深度理性、专业知识 | 结构化分析、数据支撑、专业可信 |
| 📰 公众号 | 正式结构化、排版优化 | 标题+导语+正文+CTA，可读性强 |

**一键多平台示例：** 同一款产品"21天马甲线训练营 ¥399"→
- 小红书：精致种草，配emoji，"姐妹们这个训练营真的绝了"
- 抖音：带 #马甲线挑战 话题，短句快节奏
- 朋友圈：亲切推荐，"朋友们推荐一个超棒的训练营"
- 知乎：深度分析训练原理和科学依据
- 公众号：完整的课程介绍长文，结构化排版

## 5. 功能详解

### 5.1 智能生成（核心）

**操作流程：**
1. 选行业（下拉框，6选1）
2. 选平台（下拉框，5选1）
3. 选场景（促销/新品/日常/节日，4选1）
4. 填业务信息（产品名、价格、卖点等，越详细越好）
5. 点「生成」，几秒出结果

**💡 技巧：** 业务信息写得越详细效果越好。建议包含产品名、价格、核心卖点、目标人群。

**示例：** 美甲店推广猫眼美甲

| 输入 | 输出效果 |
|------|----------|
| 行业：美业 | 盘古自动匹配美业模板，用美业行话 |
| 平台：小红书 | 种草语气、emoji、精致排版 |
| 场景：新品上市 | "新品首发"的期待感和新鲜感 |
| 产品：极光猫眼美甲 ¥198 | 突出价格+效果+适合人群 |
| 卖点：低调奢华、适合秋冬、显白 | 围绕卖点展开叙事 |

### 5.2 一键多平台改写（Pro版+）

**使用场景：** 一次活动要在5个平台发——不用手动改5次。

**操作：** 选行业+场景 → 填核心信息 → 勾选目标平台 → 一键生成

> ⚠️ 用量：生成N个平台消耗N次额度。

### 5.3 爆款标题工厂

批量生成高点击率标题。支持选择平台风格，默认20条。涵盖emoji式、疑问式、数字对比式、反转式等多种爆款公式。

### 5.4 内容日历

按月生成发布计划，输出按周排列：
- 每周主题方向
- 具体文案角度
- 发布平台+时间建议

支持添加自定义关键日期（店庆、节日、活动日）。

### 5.5 视频脚本

三种类型可选：
- **口播** — 单人面对镜头，讲观点/知识/经验
- **带货** — 产品演示+卖点讲解+转化引导
- **Vlog** — 多场景切换，生活化叙事

输出完整分镜：每段台词 + 镜头语言描述 + 时长分配 + 配乐建议。

### 5.6 直播话术（Pro版+）

填入行业、产品、价格、预计时长，输出全套话术：
1. 🎤 开场暖场 — 欢迎词+互动引导
2. 📦 产品讲解 — 核心卖点+使用演示要点
3. ❓ 答疑逼单 — 处理犹豫+限时优惠+催促下单
4. 👋 收尾预告 — 下播话术+下次直播预告

### 5.7 竞品分析（Pro版+）

两种输入方式：
- 直接粘贴竞品文案
- 输入竞品内容链接

输出：竞品策略拆解 + 你的差异化建议 + 优化版参考文案。

### 5.8 AI配图Prompt（Pro版+）

将文案内容转化为高质量AI绘图Prompt——中英双语，含构图描述、光线设定、色调方案、风格指引、质量增强词。直接复制到ComfyUI/Stable Diffusion使用。

### 5.9 历史记录

所有生成记录永久保存，支持翻页浏览和关键词搜索，方便回溯复用。

### 5.10 管理后台（管理员专用）

访问 http://localhost:18791，管理员密钥登录：
- 📊 仪表盘：总用户数、内容量、今日用量、活跃用户、7日趋势、套餐分布、预估收入
- 👥 用户管理：搜索、套餐升降级、删除
- 📝 内容管理：全量浏览、搜索、删除
- ⚙️ 系统配置：查看/切换AI模型

## 8. 常见问题

### 基础类
- **盘古和ChatGPT有什么区别？** ChatGPT是通才，盘古是垂直行业内容专家。6大行业深度模板，选行业即用，不用写Prompt。
- **能生成图片吗？** Pro版以上支持AI配图Prompt。复制Prompt到ComfyUI/Stable Diffusion即可出图。
- **视频能直接出成品吗？** 目前出分镜脚本（台词+镜头+时长+配乐），拿稿拍就行。

### 定价类
- **免费版够用吗？** 每天5次，够个体户日常发圈发帖。需要更多次数或高级功能再升级。
- **支持退款吗？** Pro版/企业版7天无理由退款。白标版签约前充分沟通。
- **年付有优惠吗？** 联系客服咨询。

### 使用类
- **怎么上手？** 选行业→选平台→填需求→点生成，四步出活。
- **支持手机吗？** 支持，响应式Web App。
- **一键多平台怎么计费？** 生成N个平台消耗N次额度。
- **历史记录保存多久？** 永久保存。
- **密码忘了？** 当前版本联系管理员重置。

### 安全类
- **我的数据会用于训练吗？** 不会。
- **白标版数据隔离吗？** 完全隔离，独立数据库。
