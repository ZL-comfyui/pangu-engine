## 项目身份
- **名称：** 盘古AI内容引擎

## 模型/API
- 主模型：deepseek-chat（通过 DeepSeek API）
- 配图：ComfyUI + SD1.5 + AnimateDiff
- 配音：Edge TTS（zh-CN-YunxiNeural）
- 合成：FFmpeg（winget Gyan.FFmpeg 8.1.2）

## 项目资产
- `prompts/` — Prompt 模板库（6行业×5平台×6工具=720+组合）
- `server/` — 后端（12个API端点）
- `web/` — 用户前端（Vanilla JS SPA）
- `admin/` — 管理后台（React+Vite）
- `docs/` — 文档+记忆+日志+安全
- `.env` — 环境变量（含API Key）
